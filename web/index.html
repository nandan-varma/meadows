Meadows

A compiled language that translates .ms source to LLVM IR. This playground runs the full front end — lexer, parser, semantic analyzer — and a tree-walking interpreter, entirely in your browser via WebAssembly. It does not run the native LLVM/clang++ pipeline (that needs a real toolchain), so interpreted output can differ in narrow, documented ways — see docs/LANGUAGE.md. Source
