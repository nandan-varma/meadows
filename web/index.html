About Meadows Compiler

Meadows is a Python-like programming language with strong static typing, compiled to native code using LLVM.

Features:

  • Python-like syntax
  • Static type checking
  • LLVM backend for optimization
  • WebAssembly compilation
  • Real-time AST visualization

Language Constructs:

  • Functions and recursion
  • Control flow (if/else, while loops)
  • Arithmetic and logical operators
  • Variable assignments
  • Print statements
